# Core dependencies for delta-forge-benchmarks (required to run the bench).
#
# These are version FLOORS, not exact pins, on purpose: a binary wheel must
# exist for whatever Python you run (3.9 through 3.14 and beyond), otherwise pip
# falls back to slow, fragile source builds. The exact versions pip resolves are
# recorded per run in manifest.json, which is what makes a result reproducible.
# install.sh installs these with --prefer-binary.
#
# Install with:
#     python3 -m venv .venv
#     . .venv/bin/activate
#     pip install --prefer-binary -r requirements.txt
#
# (install.sh / install.ps1 do this for you.)

# Engine: Spark + Delta. Kept on the 4.0 line so PyPI resolves compatible JARs.
# pyspark is distributed as an sdist (no wheel, but no compile either).

# Data: TPC-H/SSB generation + Parquet/Delta writing.
