# Pinned Python dependencies for delta-forge-benchmarks.
#
# Versions match docker/Dockerfile so a venv install on a Linux server
# behaves identically to the published Docker image.
#
# Install with:
#     python3 -m venv .venv
#     . .venv/bin/activate
#     pip install -r requirements.txt
#
# Or use scripts/install.sh which does this plus apt prerequisites.

# Data: TPC-H generation + Parquet writer.

# System metrics: process-tree RSS + CPU sampling during measured steps.

# Reporting: pandas for the optional summary frame, matplotlib + plotly for
